MKE Phase P02A Syntax Specification

MKE enforces strict mathematical explicit syntax to prevent ambiguity and silent parsing misinterpretations.

✓ Accepted Syntax

  • 2*x + 3 = 7 (Explicit multiplication with *)
  • -x^2 = 1 (Parsed as -(x^2))
  • (-x)^2 = 1 (Grouped negative base)
  • x^0 = 1 (Preserves power node; evaluated over original domain)
  • 0*x = 0 (Identity equation; solution domain \(\mathbb{R}\))
  • (x-1)/(x-1) = 1 (Rational equation preserved for candidate verification)

✗ Strictly Rejected (Syntax Errors)

  • 2x = 4 (Ambiguous implicit multiplication; use 2*x)
  • 1/2x = 1 (Implicit multiplication; use 1/(2*x) or (1/2)*x)
  • x(x+1) = 0 (Implicit multiplication; use x*(x+1))
  • x^3 = 1 (Exponent > 2 out of scope in Phase P02A)
  • 2*y = 4 (Multi-variable unsupported; single variable x only)
